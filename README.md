# departs.app

departs.app is a lightweight web app for viewing Prague's public transport departures in a clean, fast, and distraction‑free way. It’s built with a focus on speed, simplicity, and real‑time data — no clutter, no ads, just departures.
The app is designed to work great as a PWA (Progressive Web App), so you can add it to your home screen and use it like a native app.

## ✨ Features
- 🚉 Real‑time departures for Prague's public transport
- 📚 Search real-time departures including delays by stop name
- 📱 Installable as a PWA (Add to Home Screen)
- 📊 See live location of all public transport vehicles on the map
- 🎯 Focused on the essentials — no noise

## 🖥️ Live App
👉 https://departs.app

## 🚀 Development

Prerequisites:
- Node.js 
- wrangler for running Cloudflare Pages functions locally
- api.golemio.cz API key

Install:
npm install

Run locally:
npm run dev

Build:
npm run build
